# 한 걸음 — 취업 준비 워크북

취업 준비 설명·예시를 읽고 내 자료와 경험을 작성하는 정적 웹 워크북입니다. **5개 가이드의 45개 목차를 모두 사용할 수 있습니다.**

## 실행

[워크북 열기](dist/index.html). 빌드나 패키지 설치가 필요 없습니다. 기존 탭은 새로고침하면 변경 사항이 적용됩니다. 로컬 서버가 필요하면 프로젝트 폴더에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 4175 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:4175/`를 엽니다.

## 현재 기능

| 가이드 | 목차 수 | 내용 |
| --- | ---: | --- |
| AI 활용법 | 6 | AI 특징, 개인 지침, 문장 수정, Claude 원고, Canva 지표·차트, 뷰인터 실습 안내 |
| 기업 분석 | 10 | 조사 준비, 자료 수집·요약·검증, 공고·직무·자기 분석, 자기소개서 준비 |
| 자기소개서 | 10 | 문항·경험·구성 기법, 주요 문항 작성, 첨삭·최종 체크리스트 |
| IT 포트폴리오 | 10 | 필요 역량·기술·프로젝트·성과·회고, 양식 선택, Canva·Notion 제작 준비 |
| 면접 | 9 | 직무·임원 질문·답변·보완, 음성·영상·싸피엔스 모의 면접 준비와 기록 |

- 설명·가상 예시·작성 공간, 자동 저장, 완료 표시·진행률, 목차 검색, 기록 복사와 모아보기.
- JSON 전체 백업·미리보기·단계별 선택 복원·불러오기 직전 보호본, 읽기용 Markdown 내보내기.
- 작성 변경 시 완료·최종 확인 해제, 직접 수정하거나 비워 둔 요청문 및 기존 자유 메모 보존.
- 상단 **화이트 모드 / 다크 모드** 선택과 설정 유지. 본문·보조 설명은 확대된 크기이며 제목·버튼·입력 크기는 기존 기준을 유지합니다.

## 저장과 외부 도구

입력 내용은 현재 브라우저에 저장됩니다. 중요한 기록은 상단 **백업·복원**에서 JSON으로 내려받으세요. Markdown은 읽기용이며 복원할 수 없습니다. 브라우저 데이터 삭제·다른 브라우저·다른 실행 주소에서는 기존 기록에 접근하지 못할 수 있습니다.

프롬프트는 실제 입력한 자료만 조합합니다. 복사 후 외부 도구에서 직접 실행하고 결과를 가져와 검토하세요. 이 웹은 AI API를 호출하거나 작성 내용을 자동 전송하지 않습니다. 학습 완료와 실제 계정 생성·업로드·차트 제작·촬영·리포트 수신 상태는 별도로 기록합니다.

## 검증과 문서

전체 자동 검사 **462개**, JavaScript **18개** 문법 검사를 통과했습니다. 전체 목차 화면, 모바일 배치, 모드 선택과 기록 보존, 단계별 작성·복사·백업·복원을 검증했습니다. 구체적인 범위와 미검증 항목은 [문서 목차](dist/output/md_file/README.md)와 각 보고서를 확인하세요.

```sh
node --test tests/*.test.cjs
```

새 Markdown 문서와 보고서는 **`dist/output/md_file/`에 저장**합니다. 초기 검토안도 이 폴더에 모았으며 과거 보고서의 검사 수·보류 표시는 당시 기록으로 유지합니다.

## 남은 작업

1. 실제 휴대전화·운영체제 한글 입력기·다른 브라우저와 사용자 최종 검토.
2. Claude·Canva·Notion·음성/영상 면접·싸피엔스의 실제 계정 실습과 결과 기록. 표절·AI 검사 사이트 작업은 보류 상태입니다.
3. 요청 시 배포 대상 정리·기존 사이트에 반영·공개 주소 재검증.

배포와 AI API 연동은 수행하지 않았습니다. 로그인·서버 저장·기기 간 자동 동기화는 현재 범위에 포함되지 않은 선택 기능입니다. 배포 시 `.openai/hosting.json`의 기존 프로젝트를 재사용합니다.

## 파일 구성

- `dist/`: 정적 웹 소스와 문서. `dist/company-research-review.html`은 현재 워크북과 별개인 **초기 검토 화면**입니다.
- `tests/`: 자동 회귀 검사.
- `scripts/inspect-pdf.swift`: 로컬 PDF 읽기·페이지 렌더링 보조 도구.
- `.openai/hosting.json`: 기존 사이트 연결 설정. 인증키를 포함하지 않습니다.

원문 PDF·압축 파일, 임시 브라우저 검사·로그·캐시, 환경변수·인증키는 `.gitignore`에서 제외합니다. JSON 백업 등 개인 작성 기록은 저장소에 추가하지 않습니다.
