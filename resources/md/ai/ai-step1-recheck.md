# AI 활용법 1단계 재검토 — 채용 단계에 따른 AI 특징

> 이 문서는 해당 작업 시점의 기록입니다. 현재 구현 상태와 남은 작업은 [문서 목차](../README.md)를 기준으로 확인하세요.

상태: 원문 대조 후 로컬 수정·검증 완료. 다음 단계는 AI 활용법 2단계 재검토.

## 이번에 한 작업

사용자가 AI 활용법을 다시 확인하고 천천히 진행하도록 요청했다. 자기소개서 후속 구현을 중단하고 AI 활용법 1단계만 수정했다. 저장된 AI 활용법 PDF 1–3쪽 렌더링을 한 장씩 확인했다. 1쪽은 표지, 2쪽이 이번 단계, 3쪽부터 다음 단계다. 외부 자료 요청이나 병렬 작업 없이 진행했다.

기존 화면에는 원문의 추천 도구·특징과 포트폴리오 시각화·수치화 구분이 빠져 있었다. `#course/ai/0/guide`에서 원문 2쪽의 네 구분을 반영했다.

| 구분 | 원문 도구 | 원문 강조 추천 |
| --- | --- | --- |
| 기업 분석·직무 탐색 | Gemini, Claude, Perplexity | Gemini, Claude |
| 자기소개서·IT 포트폴리오 서류 작성 | ChatGPT, Gemini, Claude, 노션 AI | Gemini, Claude |
| IT 포트폴리오 시각화·수치화 | Gamma, Canva AI, Kling AI | Canva AI |
| 면접 준비·모의 면접 | Claude, ChatGPT, 뷰인터, 면접톡 | ChatGPT, 뷰인터 |

원문에 소개된 특징·활용 상황을 요약하고, 추천은 원문 표시임을 밝혀 현재 순위나 서비스 기능 보장으로 오해하지 않도록 했다. 준비 자료·확인 기준은 보완 안내로 구분했다. 기존 가상 활용 사례 4개에 검증한 프로젝트 기록을 구조도로 구성하는 시각화 사례 1개를 추가했다. 실제 도구 사용 절차나 외부 실습을 새로 구현한 것은 아니다.

작성 공간은 기존 자유 메모를 유지하고, 단계 → 작업 → 기능·도구 후보 → 제공 자료 → 결과 확인 기준 순서로 적도록 안내했다. 저장 키·데이터 구조·완료 동작은 변경하지 않았다. AI 활용법 2–3단계는 이번에 수정하지 않았으며 다음에 원문과 대조해야 한다. 기존 외부 실습 3개 보류 상태도 유지했다. 학습 가능 단계는 14/45다.

## 검증 상태

- 기존 자동 검사 216개 통과, 실패 0개.
- index.html이 사용하는 JavaScript 17개 문법 검사 통과.
- 로컬 HTTP 200, 독립 Chromium 1280×900·390×844에서 네 구분·도구 표시, 예시 5개, 탭 전환, 가로 넘침 없음 확인.
- 기존 메모 보존, 편집·자동 저장·새로고침 복원, 완료 표시 유지, 다른 단계 지침·자기소개서 기록 보존 확인.
- 페이지 스크립트 오류 없음. 데스크톱·모바일 설명 화면을 각각 시각 확인.

기존 사용자 저장소에는 접근하지 않고 독립 테스트 저장소를 사용했다. 실제 서비스 기능·요금·현재 추천 순위는 조사하지 않았다. 사용자가 보고한 429 오류의 발생 지점과 원인은 확인되지 않았으며, 이번 도구 실행에서는 429 오류가 반환되지 않았다. 429가 해결됐다고 판단하지 않는다.

## 다음에 할 작업

AI 활용법 1단계 검토 후, 2단계 ‘페르소나가 아닌 정확한 나만의 지침 프롬프트 만들기’를 원문부터 차례로 확인하고 수정한다. 자기소개서 후속 작업보다 AI 활용법 재검토를 우선한다. 로컬 작업만 수행했으며 배포·외부 AI API 연동은 하지 않았다.
