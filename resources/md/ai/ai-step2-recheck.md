# AI 활용법 2단계 — 나만의 지침 프롬프트 개선

> 이 문서는 해당 작업 시점의 기록입니다. 현재 구현 상태와 남은 작업은 [문서 목차](../README.md)를 기준으로 확인하세요.

상태: 로컬 수정·검증 완료. 다음 작업은 AI 활용법 3단계 검토.

## 이번에 한 작업

여섯 입력칸의 저장 키를 유지하면서 화면과 조합 결과를 네 부분으로 정리했다.

1. 나의 정보: 학력·교육, 기술·어학 자격, 주요·보조 기술과 실제 사용 범위, 프로젝트 경험 및 이번 작업 자료.
2. 해결하고자 하는 문제: 지원 대상·현재 준비 단계, 필요한 도움과 제약 조건.
3. 출력 방법: 형식·구성 순서·분량·공백 포함 여부·문체.
4. 마무리: 어조·금지 사항, 회사·직무·기술명과 경험을 대조할 기준, 부족한 정보에 대한 질문.

배경과 프로젝트 경험은 재사용하고, 이번에 제공할 문항·공고와 작업 조건은 다시 확인하도록 안내한다. 프로젝트를 여러 개 정리할 수 있으면 2~3개를 고르고 하나뿐이면 그 경험부터 시작하도록 했다. 자격이 없거나 결과를 측정하지 않았다면 그대로 기록한다. 기존 완성 사례 3개도 배경·경험·출력 조건·검증 기준을 구체화했다.

조합 결과에는 직접 제공한 값만 포함한다. 빈 묶음은 출력하지 않고 가상 예시를 자동으로 넣지 않는다. 기존 수동 요청문과 의도적으로 비운 요청문은 유지한다. 직접 고친 요청문을 현재 입력값으로 바꾸려면 재조합 확인을 거친다. 기존 자동 조합 요청문은 새 구조로 표시한다.

사용자의 화면 문구 요청을 반영해 공통 학습 화면의 제작 설명·자료 대조 안내·페이지 번호를 제거했다. 1단계는 도구 예시와 활용 안내를 바로 보여주며 중복 추천 표시는 제거했다. 준비 중인 단계는 ‘준비 중’으로 표시한다. 기업 조사·검증에 필요한 근거 기록과 AI 답변 보관 등 실제 학습 기능은 유지했다. 학습 가능 단계는 14/45이며 다음 단계 활성화는 하지 않았다.

## 검증 상태

- 자동 검사 **218개 통과, 실패 0개**. 기존 검사와 요청문 조합·기존 데이터 보존 검사 2개를 포함한다. 화면 문구 변경으로 달라진 기대값을 갱신했다.
- JavaScript **17개 파일** 문법 검사 통과.
- 45개 단계의 설명·예시·작성 탭 렌더링 검사에서 제작 설명 표시가 제거되었는지 확인.
- 독립 Chromium **1280×900 / 390×844**에서 네 묶음·여섯 입력칸, 기존 배경·빈 수동 요청문 보존, 내용 변경 시 완료 해제, 재조합 취소·동의, 새로고침 복원 확인.
- 합성 한글 조합 이벤트 중 입력 저장·미리보기 보류, 조합 종료 시 갱신과 같은 입력 요소 유지 확인.
- JSON·Markdown 실제 다운로드와 내용, 선택 복원, 다른 단계 기록 보존, 직전 보호본 다운로드·내용 확인.
- 중복 ID·가로 넘침·페이지 스크립트 오류 없음. 데스크톱·모바일 작성 화면을 각각 시각 확인.

사용자 브라우저 저장소에 접근하지 않고 독립 테스트 저장소를 사용했다. 외부 자료 요청이나 AI API 실행 없이 순차적으로 진행했다. 실제 운영체제 한글 키보드 입력, 외부 AI 답변의 품질과 개인 경험의 진위는 자동 검증하지 않는다. 이번 도구 실행에 429 오류는 반환되지 않았으나 사용자가 보고한 오류의 원인을 확인하거나 해결한 것은 아니다.
