## 이번에 한 작업

- 원문 PDF 6–9쪽에서 확인한 DART, DartPoint AI, 한경컨센서스와 비상장기업 조사 경로를 설명에 반영했습니다. DART에서 읽을 주요 제품·서비스, 연구개발 등 항목을 구체화했습니다.
- KIND는 원문의 사이트 목록과 구분해 추가 조사 경로로 표시했습니다. 서비스의 기능·화면·회원 조건은 PDF에 실린 안내이며 현재 이용 조건은 해당 서비스에서 확인하도록 설명했습니다.
- 가상 사업보고서와 증권사 리포트의 두 비교 사례를 작성했습니다. 사실·계획·전망을 나누고 근거 위치를 남기는 방법을 보여 줍니다.
- 자료별 카드를 추가·수정·삭제할 수 있습니다. 카드마다 기업·직무·질문, 문서·작성 주체, 원문 위치, 날짜, 사실·근거, 다음 질문의 여섯 항목을 기록합니다. 최대 20개이며 작성 내용이 있는 카드의 삭제에는 확인창이 나옵니다.
- 입력 내용을 브라우저에 저장하고 전체 자료 기록을 복사할 수 있습니다. 내 메모·Markdown·JSON 백업·선택 복원·복원 직전 보호본에도 모든 카드가 포함됩니다.
- 기존 자유 메모와 앞 단계의 직접 수정한 프롬프트를 보존합니다. 앞 단계 기록과 예시는 읽기용 참고이며 입력칸을 자동으로 채우지 않습니다.
- 한글 조합 중에도 입력은 저장하고 기록 미리보기는 조합이 끝난 뒤 갱신합니다. 타이핑 중에는 입력 요소를 교체하지 않습니다.
- 새로 완료 표시를 할 때 카드 한 개 이상과 각 카드의 여섯 항목을 확인합니다. 카드 추가·수정·삭제 후에는 완료 표시를 해제합니다. 완료는 기록 작성 점검이며 정보의 진위를 자동 판정하지 않습니다.

## 검증 상태

- Node 자동 검사 **129개 통과, 실패 0개**. 기존 116개에서 학습 가능 단계와 대기 단계 기준을 갱신하고 자료 카드·복원·화면 동작 검사 13개를 추가했습니다.
- JavaScript 파일 11개의 문법 검사 통과.
- 실제 Chromium 데스크톱(1280×900)에서 설명·탭·카드 작성·완료·수정·삭제 확인·기존 기록 보존·입력 레이블을 확인했습니다. 탭을 왕복해도 같은 입력 요소가 유지됐습니다.
- 실제 Chromium의 모바일 크기(390×844)에서 카드 재로드, 가로 넘침 없음, 16px 입력 글자, JSON·Markdown 다운로드, 복원 미리보기, 단계별 교체, 직전 보호본, 카드 20개 제한을 확인했습니다. 모바일 화면 캡처도 한 장씩 확인했습니다.
- 한글 조합 이벤트를 브라우저에서 주입해 입력 저장과 미리보기 갱신 시점을 점검했습니다. 실제 OS 한글 입력기의 수동 타이핑을 재현한 검사는 아닙니다.
- 새 브라우저 테스트 컨텍스트를 사용해 사용자 작성 기록과 분리했습니다. 검증 중 JavaScript 실행 오류는 없었습니다.

## 저장과 호환성

기존 저장 키와 백업 버전 1을 유지합니다. 새 데이터는 `worksheets['1-3'].cards` 배열에 저장하며 카드 값은 여섯 문자열 필드로 제한합니다. 백업은 알 수 없는 필드, 잘못된 값·배열, 20개 초과 카드를 거부합니다. 같은 카드의 필드 순서만 달라진 경우에는 복원 충돌로 보지 않지만, 카드 순서나 내용이 다르면 차이를 표시합니다.

이전 백업은 현재 웹에서 계속 불러올 수 있습니다. 새 자료 카드가 포함된 백업은 이 기능을 지원하는 현재 웹에서 복원해야 합니다. 로컬 저장 실패 시 안내를 표시하며 현재 화면의 기록을 복사하거나 내려받을 수 있습니다.
