## 이번에 반영한 내용

- 공식 홈페이지·최신 기사와 직접 대조하는 검증 안내. 법인·기간·단위·연결/별도 범위·정정 여부, 계획과 실적, 후속 변경·누락 정보 확인.
- 주장별 검증 카드 추가·수정·삭제·자동 저장, 최대 20개. 작성한 카드 삭제는 확인 후 진행.
- 카드 항목: 원래 주장 / 대조한 원문·위치 / 비교 기준·변경·누락 / 판단 이유 / 최종 문장 / 제외 이유·다음 확인 / 내 판단.
- 판단: 확인됨 / 수정 후 확인 / 오류 확인·제외 / 미확인. 근거 부족을 오류로 단정하지 않도록 설명.
- 카드 내용을 수정하면 해당 판단과 단계 완료를 해제. 한글 조합 중에도 수정 내용을 저장하고 이전에 선택한 문장은 즉시 목록에서 제외. 나머지 미리보기는 조합 종료 후 갱신.
- 필수 기록을 갖추고 ‘확인됨’·‘수정 후 확인’으로 선택한 카드만 문장 모음에 포함. 미확인·오류·판단 전 기록은 전체 검증 기록에 보존.
- 선택적 검증 요청문 조합·편집·복사. 직접 수정한 요청문은 카드 수정으로 덮어쓰지 않으며, 의도적으로 비운 요청문도 유지. 재조합 시 수정본 교체 확인. 재조합은 카드 판단을 바꾸지 않음.
- 4단계 자료와 5단계 분석·답변 원문·수동 지침·자유 메모를 읽기 전용으로 참고. 자동 입력·전송·판정 없음.
- 가상 비교 사례 3개: 단위·기간·범위 혼동, 출처에 없는 기술, 계획과 후속 철회 발표.
- 내 메모·Markdown 내보내기·JSON 백업·선택 복원·직전 보호본·목차 진행 상태와 연결.
- AI 활용법 1–3단계 + 기업 분석 1–6단계, 총 9개 단계 사용 가능.

## 원문과 편집 범위

[기업 분석 PDF](../../pdf/2-company-analysis-source.pdf) 13쪽과 [앞선 비교 보고서](company-analysis-4-6-comparison.md)를 사용했습니다. 기존 PDF 페이지 이미지를 한 장만 확인했습니다.

원문은 AI 답변을 비판적으로 읽고, 공식 홈페이지·최신 기사와 직접 대조하며 정확성과 누락을 점검하도록 안내합니다. 현대오토에버는 검증 요청문의 예시로 소개됩니다.

검증 카드, 가상 사례, 상태 구분은 보완 콘텐츠입니다. 원문의 ‘확인할 수 없으면 정확하지 않다고 말하기’ 표현을 그대로 사용하지 않고, 확인 불가와 근거로 확인한 오류를 구분했습니다. ‘수정 후 확인’은 수정 문장까지 직접 대조한 경우이며 ‘오류 확인·제외’는 원래 주장을 사용하지 않는 경우입니다.

## 완료와 저장

카드 한 개 이상에서 주장·원문·비교 기준·판단 이유·다음 확인·상태를 작성해야 완료할 수 있습니다. 확인됨·수정 후 확인 카드는 최종 문장도 필요합니다. 미확인 카드를 포함한 조사 기록도 완료할 수 있으며, 완료는 모든 정보의 사실 인증이 아닙니다. 미완성 카드는 선택한 문장 모음에서 제외합니다.

`worksheets['1-5'] = { cards: [...], custom?: string }`

카드 문자열 필드: `claim`, `source`, `comparison`, `reason`, `final`, `next`, `verdict`.
판단 값: 빈 문자열(판단 전), `confirmed`, `corrected`, `error`, `unverified`.

기존 localStorage 키와 JSON 백업 버전 1을 유지합니다. 이전 백업은 읽을 수 있으며, 새 검증 필드를 지원하지 않는 이전 앱은 새 백업을 거절합니다. 잘못된 배열·객체·필드·자료형·판단 값·20개 초과는 백업 검사에서 거절합니다. 복원 시 불완전한 완료 표시는 해제하며, 카드 순서는 보존합니다. 자동 요청문 자체는 빈 기록으로 내보내지 않습니다. 카드 내용과 직접 수정한 요청문만 기록으로 취급합니다.

## 검증

- 자동 검사 **157개 통과, 0개 실패**. 기존 141개를 학습 가능 범위에 맞게 갱신하고 모델 10개·화면 어댑터 6개 추가.
- JavaScript **13개 파일** 문법 검사 통과.
- 실제 Chromium 데스크톱 1280×900: HTTP 200, 카드 작성·판단·완료·수정 시 해제, 미확인 문장 제외, 요청문 수정본 보존·재조합 취소, 새로고침 보존, 삭제 취소·승인.
- 합성 IME 이벤트에서 조합 중 저장·이전 판단 해제·선택 문장 즉시 제외, 조합 종료와 새로고침 후 한글 보존 확인.
- 모바일 크기 390×844: 작성·예시·가이드 가로 넘침 없음, 입력·선택 글꼴 16px, 탭 변경 시 작성 DOM 보존, 20개 카드 한도.
- JSON·Markdown 실제 다운로드 검사. 미확인 기록과 기존 메모 보존. 파일 선택·미리보기만으로 현재 기록이 바뀌지 않음. 선택 복원과 복원 직전 보호본 검사.
- 6단계 복원 후에도 4단계 자료 및 5단계 원문·분석 메모·수동 요청문 보존 확인.
- 모델 검사: 상태별 완료 조건, 미완성·미확인 문장 제외, 검토 의견을 원문으로 승격하지 않는 요청문, 데이터 정리·깊은 복사, 잘못된 백업·판단 값 거절, 순서 보존, 검색에 개인 내용 미포함.
- 독립 브라우저 컨텍스트를 사용해 사용자 기록에 접근하지 않았으며, 테스트 중 JavaScript 페이지 오류 없음. 데스크톱·모바일 스크린샷을 한 장씩 확인.

실제 휴대폰·운영체제 한글 키보드와 외부 서비스의 현재 기능, 실제 기업 정보의 진위는 검증 범위에 포함하지 않습니다.
