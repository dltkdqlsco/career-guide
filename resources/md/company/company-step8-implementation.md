## 이번에 반영한 내용

- 분석할 기업·직무·채용 수준·선택 이유와 지원 공고 원문·출처 기록.
- 공고 특징 → 강점 키워드 1~2개와 업무·역량 연결 근거 → 필요한 경험 유형의 분석 구조.
- 실제 경험이 제공된 경우에만 연결 후보를 검토하고, 미제공이면 미연결·다음 확인으로 남기는 안내.
- 지원 공고와 유사·경력직 참고 공고를 구분. 비교 자료가 없으면 공고의 차별성을 단정하지 않도록 요청.
- 선택 직무·지원 공고·실제 경험·비교 자료 네 입력칸으로 분석 요청문 조합·수정·복사. 받은 답변·작성 중인 분석은 요청문의 제공 자료로 자동 편입하지 않음.
- AI 답변 원문과 직접 작성하는 분석을 별도 보관. 수동 수정 요청문과 의도적으로 비운 요청문도 입력 변경으로 덮어쓰지 않음. 재조합 시 수정본 교체 확인.
- 외부 AI를 사용하지 않는 직접 분석도 지원. 작성 필수 7개, 선택 4개 항목. 두 번째 키워드·실제 경험·참고 공고·AI 원문은 선택.
- 7단계 지원 공고·원문·참고 공고·적용 한계·자유 메모를 읽기 전용으로 참고. 자동 입력 없음.
- 가상 비교 사례 2개: 백엔드 공고와 실제 경험 연결, 고객 운영 공고에서 경험 미제공·경력직 참고 한계 구분.
- 자동 저장·기록 복사·내 메모·Markdown·JSON 백업·선택 복원·진행 상태와 연결. 작성 내용 변경 시 완료 해제.
- AI 활용법 1–3단계와 기업 분석 1–8단계, 총 11개 단계 사용 가능.

## 저장과 완료 조건

`worksheets['1-7']`의 문자열 필드:

`target`, `posting`, `experience`, `comparison`, `original`, `features`, `keyword1`, `keyword2`, `experienceTypes`, `matches`, `questions`, `custom`

`target`, `posting`, `features`, `keyword1`, `experienceTypes`, `matches`, `questions`가 작성 필수입니다. 실제 경험을 아직 제공하지 않았다면 미연결과 다음 행동을 기록할 수 있습니다. 키워드 2개나 AI 답변을 억지로 채울 필요가 없습니다. 요청문도 선택적 보조 기능이므로 의도적으로 비운 수동 요청문이 완료를 막지 않습니다. 완료는 분석 기록 작성 점검이며 직무 적합도·합격 가능성의 자동 평가가 아닙니다.

기존 localStorage 키와 JSON 백업 버전 1을 유지합니다. 이전 백업은 읽을 수 있으며, 새 필드를 지원하지 않는 이전 앱에서는 8단계 기록이 포함된 백업을 거절합니다. 잘못된 필드·자료형은 백업 검사에서 거절하고 미완성 기록의 완료 표시는 복원 시 해제합니다. 7단계 원문·참고 공고·적용 한계와 다른 단계 수동 지침을 유지합니다.

## 검증

- 자동 검사 **180개 통과, 0개 실패**. 기존 168개를 새 학습 가능 범위에 맞게 갱신하고 모델 8개·화면 어댑터 4개 추가.
- JavaScript **15개 파일** 문법 검사 통과.
- 실제 Chromium 데스크톱 1280×900: HTTP 200, 빈 기록, AI 답변·두 번째 키워드 없이 직접 분석 완료, 입력 변경 시 완료 해제, 수동 요청문 재조합 취소, 원문·수동 요청문 새로고침 보존, 탭 변경 시 작성 DOM 보존.
- 모바일 크기 390×844: 작성·예시·가이드 가로 넘침 없음, 입력 글꼴 16px. 합성 IME 이벤트 중 저장과 조합 종료 후 한글·이모지 보존.
- JSON·Markdown 실제 다운로드 내용 확인. 공고 근거·수동 요청문·기존 메모 포함.
- 파일 선택·미리보기로 기록이 변경되지 않음. 8단계 선택 복원 및 복원 직전 보호본 검사. 7단계 원문·참고 자료·적용 한계와 이전 수동 지침 보존.
- 모델·화면 어댑터: 선택 항목·완료 조건, 네 준비 필드만 요청문에 포함, 미제공 경험·비교 자료 처리, 수동·빈 요청문 보존, 원문과 분석 분리, 백업 오류 거절·불완전 완료 해제, 선택 복원, 개인 경험을 검색 내용에 미포함.
- 독립 브라우저 컨텍스트 사용, 사용자 기록에 접근하지 않음. JavaScript 페이지 오류 없음. 데스크톱·모바일 스크린샷을 한 장씩 시각 확인.

실제 휴대폰·운영체제 한글 키보드, 외부 AI의 응답 품질, 실제 채용 요건과 개인 경험의 진위는 검증 범위에 포함하지 않습니다.
