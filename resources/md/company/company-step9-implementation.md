# 기업 분석 9단계 — 자기분석

> 이 문서는 해당 작업 시점의 기록입니다. 현재 구현 상태와 남은 작업은 [문서 목차](../README.md)를 기준으로 확인하세요.

상태: 구현·검증 완료, 사용자 검토 대기. 다음 단계로 진행하지 않음.

## 확인 위치

`index.html#course/company/8/write` 또는 기업 분석 → 9. 자기분석.
현재 학습 가능: AI 활용법 1–3단계 + 기업 분석 1–9단계 = 12 / 45.
기업 분석 10단계와 자기소개서 1–3단계의 이전 초안은 비활성 상태로 보관한다. 해당 초안에 입력 기록이 있을 가능성을 고려해 저장·백업 스키마는 유지하지만 학습 화면은 열지 않는다. AI 활용법의 보류 안내 3개(0-3~0-5)도 그대로 유지한다.

## 원문과 구현

기존에 한 장씩 확인한 기업 분석 PDF 17–18쪽을 기준으로 구성했다.

| PDF 주제 | 구현 |
|---|---|
| 공고의 필요 역량·강점 키워드와 내 경험 비교 | 희망 기업·직무·산업, 공고 근거, 실제 경험 입력 |
| 학력·교육·자격·기술·프로젝트 배경 제공 | 교육·기술 사용 범위·직접 맡은 역할·행동·결과·확인 자료 안내 |
| 역량·경험 매칭, 강점과 약점 분석 | 역량별 연결 근거·강점과 부족한 근거·다음 행동 입력 |
| AI 적합도 평가 사례 | 참고 의견으로 설명하며 자동 점수·합격 가능성 판정은 제공하지 않음 |

필수 작성칸은 5개다. AI 원문 보관과 요청문은 선택이며, 직접 분석만으로 완료할 수 있다. 가상 예시, 근거 구분 규칙, 최종 확인 체크는 학습용 보완 내용이다. 원문의 기업 사례를 현재 채용 사실로 제시하지 않는다.

## 동작

- 앞 단계 직무 분석을 읽기 전용으로 참고. 자동 채우기나 기존 기록 덮어쓰기 없음.
- 요청문은 목표·공고 근거·실제 경험 3개 입력만 사용. AI 답변 원문과 사용자의 연결·보완 판단은 요청 자료에 자동 포함하지 않음.
- 직접 수정한 요청문과 의도적으로 비운 요청문 보존. 재조합은 수동 요청문 교체 확인 후 실행.
- 5개 항목과 최종 확인이 갖춰져야 완료. 항목·원문·요청문 변경 및 재조합 시 최종 확인과 완료 해제. 동일 입력 이벤트는 확인 상태를 바꾸지 않음.
- 자동 저장, 기록 복사, Markdown, JSON 백업·선택 복원·직전 보호본 연동. 기존 저장 키·백업 버전 유지.
- 체크 표시만 있는 빈 양식은 ‘작성 중’으로 집계하지 않음.

## 검사 결과

- Node 자동 검사 **192개 통과, 0개 실패**. 기존 회귀 검사와 신규 자기분석 12개 검사 포함.
- index.html이 불러오는 JavaScript **17개 파일 문법 검사 통과**.
- 독립 Chromium 컨텍스트에서 **1280×900 / 390×844** 각각 확인:
  - 빈 양식 완료 차단, 직접 분석·빈 요청문 완료, 수정 시 확인·완료 해제.
  - 예시 자동 입력 없음, 읽기 전용 참조·사용자 글 이스케이프.
  - 조합 중 즉시 저장·미리보기 보류, 조합 종료 후 갱신, 입력 DOM 유지.
  - 재조합 취소·동의, 수동 요청문·원문 보존, 새로고침 복원, 탭 전환.
  - JSON·Markdown 실제 다운로드 및 내용 검사, 9단계 선택 복원, 8단계·보류 초안 보존, 직전 보호본 실제 다운로드.
  - 중복 ID·가로 넘침·페이지 스크립트 오류 없음. 테스트 중 외부 네트워크 요청 없음.
- 데스크톱·모바일 작성 화면 캡처를 각각 시각 확인.

브라우저 검사에서 공통 작성칸의 composition 이벤트를 속성으로 연결하면 Chromium에서 호출되지 않는 문제를 재현했다. `addEventListener`로 고쳐 조합 종료 시 미리보기 갱신을 검증했다. 이전 단계를 포함하는 공통 작성칸의 회귀 검사도 통과했다. IME 검사는 합성 CompositionEvent/InputEvent 기반이며 실제 운영체제 한글 키보드 입력 검사는 아니다.

외부 AI 답변 품질, 실제 채용 요건, 사용자의 경험 진위는 자동 검증하지 않는다. 배포·소스 동기화·외부 AI API 연동은 하지 않았다. 테스트는 독립 브라우저 저장소에서 수행했으며 기존 사용자 브라우저 기록을 읽거나 변경하지 않았다.

## 검토할 내용

1. 공고 역량 → 내 실제 경험 → 연결 근거 → 보완 행동 흐름이 적절한지.
2. 5개 필수 작성칸과 별도 AI 도움받기 영역의 분량이 적절한지.
3. 확인 후 기업 분석 10단계 ‘자기소개서 작성 사전 준비’ 진행 여부.
