상태: 로컬 구현·검증 완료, 사용자 검토 대기.

## 이번에 한 작업

확인 위치: `index.html#course/essay/0/write` 또는 자기소개서 → 1. 자기 소개서 문항별 의도 파악.

제공된 자기소개서 PDF 2쪽의 기존 렌더링 한 장을 직접 확인했다. 문항 의도·핵심 역량 파악, 지원 공고의 업무·필요 자격·우대 사항 제공, 정보 부족 시 경쟁사 동일 직무 또는 지원 기업 경력 공고 참고, 추천 경험·어필 방향·추가 확인 사항을 반영했다. 양식·가상 사례·근거 구분 규칙과 최종 확인 절차는 학습용 보완 내용이다.

필수 작성칸은 지원 대상·문항·분량, 공고와 공개 기준의 근거, 질문 의도·핵심 역량과 해석 근거, 필요 경험 요소·어필 방향·추가 확인의 4개다. 실제 경험과 AI 요청문·받은 답변은 선택이다. 직접 분석만으로도 최종 확인 후 완료할 수 있다. 공개 기준과 추정한 의도, 지원 공고와 참고 공고의 적용 한계를 구분하며, 근거 없는 평가 배점이나 숨은 의도를 사실로 확정하지 않도록 안내한다.

채용 공고·자기분석·자기소개서 사전 준비 기록은 읽기 전용으로 참고한다. 요청문에는 현재 단계에서 직접 제공한 문항·공고·선택형 실제 경험만 포함한다. 앞 단계 기록·AI 원문·사용자 해석을 제공 자료로 자동 삽입하지 않는다. 최신 동향과 기업 전략은 확인한 출처가 있을 때만 사용하도록 안내한다.

기존 문항 분석 초안의 4개 필드·원문·수동 또는 빈 요청문·자유 메모를 보존한다. 기존 저장 키와 JSON 백업 버전 1을 유지하며 자동 저장·기록 복사·Markdown·전체 JSON·선택 복원·직전 보호본을 지원한다. 작성 내용·원문·요청문 변경과 재조합 시 최종 확인·완료를 해제하고, 같은 입력값의 중복 이벤트는 완료를 해제하지 않는다. 수동 요청문 재조합은 교체 확인을 따른다.

현재 학습 가능: AI 활용법 1–3단계 + 기업 분석 1–10단계 + 자기소개서 1단계 = **14 / 45**. 자기소개서 2–3단계의 이전 초안은 비활성으로 보존하며 외부 안내 3개의 보류도 유지한다.

## 검증 상태

- Node 자동 검사 **216개 통과, 0개 실패**. 기존 회귀 검사와 신규 모델 7개·화면 어댑터 5개 검사를 포함한다. 기존 검사에서 문항 분석의 대기 상태를 가정하던 기대값과 자유 메모 경로를 새 학습 가능 범위에 맞게 갱신했다.
- index.html이 불러오는 JavaScript **17개 파일** 문법 검사 통과.
- 로컬 HTTP 200 확인 후 독립 Chromium 컨텍스트에서 데스크톱 **1280×900**, 모바일 **390×844** 검사 통과.
- 빈 양식 완료 차단, 실제 경험·AI 답변 없이 직접 분석 완료, 빈 요청문 유지, 변경 시 확인·완료 해제, 원문·수동 요청문 보존, 재조합 취소·동의와 새로고침 복원 확인.
- 합성 한글 조합 중 즉시 저장·미리보기 보류, 조합 종료 시 갱신과 입력 DOM 유지 확인.
- 설명·예시·작성 탭 가로 넘침 없음. 중복 ID·페이지 스크립트 오류 없음. 작성 화면 데스크톱·모바일 캡처 각각 시각 확인.
- JSON·Markdown 실제 다운로드와 내용, 문항 분석 선택 복원, 다른 단계 원문·수동 요청문과 비활성 초안 보존, 직전 보호본 실제 다운로드와 내용 확인.
- 모델·화면 어댑터에서 기존 문항 분석 초안 보존, 읽기 전용 참조 이스케이프, 요청문 입력 범위, 잘못된 백업 거절·미완성 완료 해제, 개인 기록 비검색 확인.

브라우저 검사는 독립 저장소에서 수행했으며 사용자 브라우저 기록을 읽거나 수정하지 않았다. 외부 AI API·외부 네트워크 요청 없이 확인했다. 합성 IME 이벤트는 실제 운영체제 한글 키보드 입력 검사를 대체하지 않는다. 기업 정보·개인 경험의 진위, 실제 평가 기준과 외부 AI 답변의 품질은 자동 검증하지 않는다.
