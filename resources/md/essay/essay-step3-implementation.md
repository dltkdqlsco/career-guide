# 자기소개서 3단계 — 주요 자기소개서 작성 기법

> 이 문서는 해당 작업 시점의 기록입니다. 현재 구현 상태와 남은 작업은 [문서 목차](../README.md)를 기준으로 확인하세요.

상태: 로컬 구현·검증 완료, 사용자 검토 대기.

## 이번에 한 작업

- 자기소개서 3단계를 활성화했다. 전체 45단계 중 16단계를 사용할 수 있다.
- 설명을 문항·대표 경험 확인 → STAR 경험 구성 → KPI 목표·측정 근거 → FAB 강점·기여 연결 → 문항별 개요 완성 순서로 구성했다.
- STAR의 상황·과제·행동·결과와 배운 점, KPI의 목표·지표·단위·조건·전후 값·확인 자료, FAB의 특징·장점·기여 계획을 구분한다. 문항별로 강조할 기법을 안내하고 세 기법을 모두 완성문에 넣을 필요는 없음을 설명한다.
- 다섯 필수 작성칸 question / star / kpi / fab / outline과 기존 저장 키를 유지했다. 사용하지 않는 기법은 생략 이유와 대체 구성을, 미측정 결과는 이유와 확인 가능한 자료를 적을 수 있다.
- 앞 단계의 문항 분석·대표 경험 기록은 읽기 전용으로 참고한다. 자동으로 옮기지 않는다.
- 가상 SQL 오류 수정 경험을 일관된 예시로 사용했다. 성능을 측정하지 않은 경우 테스트 통과·코드·실행 기록으로 결과를 설명하고, 운영 성과로 확대하지 않는다. 별도의 감소율 계산 예시는 내 성과로 사용하지 않도록 안내한다.
- 선택형 요청문에는 제공한 문항·STAR·KPI·FAB만 포함한다. 최종 개요나 AI 원문을 입력 근거로 자동 재사용하지 않는다. 수동 요청문과 의도적으로 비운 요청문, AI 원문, 기존 초안·자유 메모를 보존한다.
- 다섯 항목과 최종 확인으로 완료할 수 있다. AI 사용은 선택이며, 수정하면 확인·완료 표시가 해제된다.

## 자료 확인 기록

로컬 `resources/pdf/3-essay-source.pdf` 10–12쪽을 렌더링해 시각 확인했다. 10쪽의 STAR 정의·각 요소와 활용 문항, 11쪽의 KPI 정의·성과 표현, 12쪽의 FAB 정의·직무 강점·지원 동기·입사 후 포부 활용을 반영했다. 원문의 예시 수치를 실제 성과로 옮기지 않도록 측정 조건·기간·단위·집계 기준과 기록을 확인하는 안내를 보완했다. 학습 화면에는 제작 설명·PDF 페이지 번호를 추가하지 않았다.

## 검증 상태

- 자동 검사 238개 통과, 실패 0개. 새 단계의 필수 항목·완료, 입력 자료만으로 요청문 조합, 기존 초안·수동·빈 요청문·AI 원문 보존, 내보내기·선택 복원, 검색·진행 상태와 UI 입력 처리 검사 10개를 추가했다. 학습 가능 범위 기대값을 16개로 갱신했다.
- JavaScript 17개 파일 문법 검사 통과.
- 독립 Chromium 1280×900 / 390×844에서 여섯 입력 요소(필수 5개·선택 원문 1개), 빈 입력 완료 차단, 최종 확인 후 완료, 수정 시 확인·완료 해제, 수동 요청문·AI 원문 보존 확인.
- 합성 한글 조합 이벤트 중 입력 저장·미리보기 보류, 조합 종료 후 갱신과 입력 요소 유지 확인.
- 재조합 취소·동의, 빈 수동 요청문 유지, 새로고침 후 완료·확인·입력 복원 확인.
- 실제 JSON·Markdown 다운로드 내용, 선택 복원의 기본 유지값, 선택 단계만 복원, 다른 단계 보존, 직전 보호본 다운로드 내용 확인.
- 설명·예시·작성 탭에서 가로 넘침·중복 ID·페이지 스크립트 오류 없음. 데스크톱·모바일 작성 화면 시각 확인.
- 사용자 저장소 대신 독립 테스트 저장소를 사용했다. 운영체제의 실제 한글 키보드, 외부 AI 답변 품질과 경험의 사실 여부는 자동 검증하지 않는다.
