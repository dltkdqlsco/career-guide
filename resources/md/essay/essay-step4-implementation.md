# 자기소개서 4단계 — 지원 동기 및 입사 후 포부

> 이 문서는 해당 작업 시점의 기록입니다. 현재 구현 상태와 남은 작업은 [문서 목차](../README.md)를 기준으로 확인하세요.

상태: 로컬 구현·검증 완료, 사용자 검토 대기.

## 이번에 한 작업

- 자기소개서 4단계를 활성화했다. 전체 45개 중 17개를 사용할 수 있다. 이후 단계와 외부 안내 보류 상태는 유지했다.
- 기업·직무 근거 → 실제 관심 계기와 선택 이유 → FAB로 입증한 경험·역량 → 초기·이후 기여 계획 → 두괄식 초안과 최종 점검의 설명을 제공한다.
- 필수 작성칸 question / evidence / experience / motivation / plans / draft 여섯 개와 최종 확인을 추가했다. AI 요청문·원문은 선택이며 직접 작성으로도 완료할 수 있다. 초안 칸은 8줄 높이로 표시한다.
- 회사 사실·지원자의 해석·미확인 목표, 팀 성과·내 행동, 과거 결과·미래 계획을 구분한다. 회사 목표를 모르더라도 확인된 공고 업무를 기준으로 본인의 기여 계획을 세울 수 있다.
- 기업 고유성, 구체적 행동, 실행 가능한 계획, 계기·포부의 표현과 논리 중복, 산업·직무 연결을 점검한다. 기업명·직무명·기술명·수치와 실제 제출창의 분량·기한을 다시 확인하도록 안내한다.
- 가상 주문 통합 서비스·채용 공고, SQL 오류 수정 경험, 기여 계획을 연결한 예시를 제공한다. 본문과 제출 전 확인 메모는 구분하며, 예시는 자동 입력하지 않는다. 실제 기업 사례의 사업·기술·성과를 사용자의 사실로 옮기지 않는다.
- 앞 단계 사전 준비·경험 선택·작성 기법 기록은 읽기 전용 참고다. 기존 자유 메모와 다른 단계 기록을 보존한다.
- 요청문에는 제공된 다섯 준비 항목만 넣는다. 사용자 초안·AI 답변은 자동 재사용하지 않는다. 검토용 초안과 확인 질문을 분리하도록 요청하며, 없는 회사 전략·경험·수치를 만들지 않도록 안내한다.

## 자료 확인 기록

로컬 `resources/pdf/3-essay-source.pdf` 13–16쪽을 렌더링해 시각 확인했다. 13쪽의 직무 관심 계기·역량을 키운 노력·입사 후 성장 계획과 FAB, 14쪽의 문항·분량·두괄식·기술과 경험 근거·명칭 검증, 15쪽의 일반론을 기업·직무 분석으로 구체화하는 보완, 16쪽의 구성과 다섯 자가 점검 기준을 반영했다. 실제 기업 사례의 전략·서비스·성과 수치는 가상 사례와 구분하며, 학습 화면에는 제작 설명·PDF 페이지 번호를 추가하지 않았다.

## 검증 상태

- 자동 검사 248개 통과, 실패 0개. 새 필수 항목·완료 조건, 입력 자료만 조합, 한글·원문·수동·빈 요청문과 기존 메모 보존, JSON·내보내기·선택 복원, 검색·진행 상태, UI 입력·확인 해제 등 검사 10개를 추가했다.
- JavaScript 17개 파일 문법 검사 통과.
- 독립 Chromium 1280×900 / 390×844에서 필수 6개·선택 원문 1개, 빈 입력 완료 차단, 작성·최종 확인 후 완료, 초안 수정 시 확인·완료 해제, 수동 요청문·AI 원문 보존 확인.
- 합성 한글 조합 이벤트 중 입력 저장·미리보기 보류, 조합 종료 후 갱신과 동일 입력 요소 유지 확인.
- 재조합 취소·동의, 의도적으로 비운 요청문, 새로고침 후 입력·확인·완료 복원 확인.
- 실제 JSON·Markdown 다운로드 내용, 선택 복원의 기본 유지값, 선택 단계만 복원, 다른 단계 기록 보존, 직전 보호본 다운로드 내용 확인.
- 설명·예시·작성 탭의 가로 넘침·중복 ID·페이지 스크립트 오류 없음. 데스크톱·모바일 작성 화면과 한글 초안을 넣은 모바일 8줄 입력 화면 시각 확인.
- 사용자 저장소 대신 독립 테스트 저장소를 사용했다. 운영체제의 실제 한글 키보드, 외부 AI 답변의 품질, 개인 경험과 기업 정보의 진위는 자동 검증하지 않는다. 분량은 입력 길이 자동 인증 없이 제출 화면에서 확인한다.
