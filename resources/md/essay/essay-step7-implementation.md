## 이번에 한 작업

- 공동 목표와 난관 → 서로의 우려·내 책임 → 판단 기준과 비교 근거 → 경청·제안·수정·합의·실행 → 실제 변화·한계·배운 점 → 초안 흐름을 제공한다.
- 필수 항목 question / context / criteria / actions / results / draft 여섯 개와 최종 확인을 추가했다. 요청문·AI 원문은 선택이며 기존 자유 메모와 다른 단계 기록을 보존한다. 초안은 기존 8줄 입력 방식을 사용한다.
- 상대가 실제로 말한 우려와 내 해석을 나누고 성격·동기를 단정하지 않는다. 내 처음 제안의 한계, 피드백 후 수정한 점, 공동 결정·팀원 실행과 내 역할을 구분한다. 협업 문항에 없는 갈등이나 리더 역할을 만들어 넣지 않도록 안내한다.
- 가상 API 오류 응답 조율 사례를 사용한다. 전면 통일 제안과 화면 담당자의 일정·수정 범위 우려를 응답 예시로 비교하고, 필수 항목 우선 적용으로 내 안을 수정해 공동 합의·문서화·연동 검증한다. 추가 항목은 후속 논의로 남긴다.
- 미합의·부분 해결과 미측정 만족도·신뢰도는 그대로 기록한다. 실제 측정 자료가 없다면 합의 문서·변경 이력·테스트로 변화를 설명한다. 갈등 요인, 판단 원칙, 근거 기반 소통, 실제 변화, 직무 연결을 점검한다.
- 앞 단계 문항 분석·경험 선택·작성 기법을 읽기 전용으로 참고한다. 예시·참고 기록은 자동으로 입력하지 않는다.
- 요청문에는 제공한 다섯 준비 항목만 포함하고 사용자 초안·AI 원문은 자동 재사용하지 않는다. 초안·점검·추가 질문을 구분하도록 요청하며 수동·빈 요청문과 원문을 보존한다.
