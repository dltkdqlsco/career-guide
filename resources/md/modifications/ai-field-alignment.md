# AI 입력 항목·예시 통일

2026-10-18. [modify.md](modify.md)의 최신 요청 2개를 반영했다.

1. **AI 원문 수정 작성 공간**: 원문 보관·문제 분석·실제 행동과 근거·수정본의 목적에 맞춰 비교 제목과 설명을 분리했다. 원문 칸은 과장된 AI 문장을 수정 없이 보관하는 예시임을 설명한다. 각 칸의 펼침 예시와 입력창 예시는 `Workbook.revisionFields`의 같은 문자열을 사용한다. 문제 분석 항목명에는 수정 이유·수정 방향을 명시했다. 네 칸은 동일한 API 오류 응답 협업 사례를 이어 보여주며, 실제 기록을 바꾸거나 예시를 자동 입력하지 않는다.
2. **나만의 지침 예시와 작성 공간**: 두 탭 모두 `Workbook.promptGroups`의 묶음·필드 순서를 사용한다. 나의 정보(나의 배경, 사용할 자료와 실제 경험) → 해결하고자 하는 문제(목표 직무와 준비 단계, 이번에 도움받을 작업) → 출력 방법(원하는 결과 형식) → 마무리(지켜야 할 기준)로 통일했다. 그룹 설명과 01–06 번호도 동일하다. 세 완성 사례와 기존 프롬프트 조합·저장 키는 유지한다.

검증: 전체 자동 검사 468개 통과(두 탭의 순서·번호 일치 및 수정 예시 일치 회귀 검사 포함), 변경 JavaScript 문법 검사와 `git diff --check` 통과. 독립 Chrome에서 1280px·390px·320px의 AI 6개 단계×3개 탭을 확인했다. 예시 항목·번호, 수정 입력창과 펼침 예시 일치, 복사·완료 조건의 기존 동작, 가로 넘침·페이지 오류를 검사했다. 390px 문장 수정 화면을 시각적으로 확인했다. 배포와 외부 AI 실행은 수행하지 않았다.
