# 공통 정보와 프롬프트 관리 구현

2026-10-19. 갱신된 [modify.md](modify.md) 전체와 사용자가 승인한 조정안을 반영했다. 기존 5개 가이드·45개 단계, 완료 기록과 작성값은 유지했다. 공통 프로필과 별도의 공통 AI 설정을 추가하고, 기존 카테고리의 39개 작업에서 프롬프트 편집 화면으로 연결했다.

## 사용 경로

1. 홈의 **공통 정보를 한 번만 입력하기**를 펼쳐 전공·희망 직무·관심 산업·기술 스택을 선택한다. 입력 없이 가이드를 바로 사용할 수도 있다.
2. **공통 프로필**에서 학력·교육, 언어·기술 숙련도, 희망 조건, 프로젝트·실무 경험, 자격·활동, 개인 역량을 필요한 만큼 추가한다. 프로젝트는 여러 개를 별도로 보관한다.
3. **공통 AI 설정**에서 역할·응답 형식·문체·언어·분량·규칙 등을 작성한다. AI 활용법에서 실제 작성한 지침 항목을 선택해 복사할 수도 있다.
4. 카테고리 제목의 **공통 정보로 프롬프트 만들기**, 또는 작성 공간의 **공통 정보·내 항목으로 프롬프트 구성하기**를 사용한다.
5. 한 편집 화면에서 정보 선택 → 항목 구성·수정 → 미리보기·저장을 진행한다. 좁은 화면에서는 **항목 구성 / 미리보기·저장**을 전환해 긴 화면을 오가지 않아도 된다.
6. 상단 **내 메모**에서 폴더별 저장본을 조회·수정·이름 변경·이동·복제·삭제한다. 기존 학습 기록과 자유 메모는 아래 접힌 영역에서 계속 볼 수 있다.

## 요청별 반영

| 요청 | 구현 |
| --- | --- |
| 폴더 기반 관리 | 한 단계 폴더 생성·이름 변경·삭제, 프롬프트 폴더 이동, 이름/내용 검색, 목록 더 보기 |
| 여러 프롬프트 저장·재사용 | 새 이름으로 저장, 저장본 열기·수정, 원본에 명시적으로 변경 저장, 독립된 복제본, 작성 중 구성의 재개·삭제 |
| 공통 프로필 | 초기 핵심 4종, 상세 6개 묶음, 선택형·복수 선택·직접 추가, 자동 저장, 프로젝트별 선택 |
| 공통 AI 설정 | 기본 규칙 가져오기, 직접 항목 추가, AI 활용법 지침의 선택적 복사, 카테고리별 추천 범위 |
| 카테고리 커스터마이징 | 기본 항목별 포함/제외·문구/이름 수정·삭제, 새 항목, 위/아래 순서 이동 |
| 선택적 조합 | 공통 프로필·AI 설정·카테고리·직접 추가 항목의 출처 표시, 체크한 비어 있지 않은 항목만 조합 |
| 추천·충돌 안내 | 카테고리별 추천 순서, 동일 내용 중복, 서로 다른 형식·문체·언어·분량 조건 안내 |
| 미리보기와 편집 | 자동 조합, 직접 최종 편집, 수동/자동 상태 표시, 명시적인 다시 조합, 복사 및 클립보드 실패 시 선택 대체 |
| 설정 보존 | 저장할 때 원문과 포함 여부·순서·항목 내용·출처·최종 편집본을 함께 복사해 보관 |
| 기존 결과 보존 | 프로필·AI 규칙의 변경/삭제가 저장본을 바꾸지 않음. 열린 구성에서 최신 정보 반영을 선택하고, 원본 변경 저장까지 별도로 실행 |

추천 정보는 처음에 프로필 6개·AI 설정 4개까지 보여 주고 나머지는 펼쳐 선택한다. 여러 항목을 고르거나 순서를 바꿀 때 펼쳐 둔 목록과 편집 상태를 유지한다. 선택한 공통 항목은 카테고리별로 기억해 이후 새 구성에 재사용한다.

## 저장·복원

- 기존 localStorage 키와 기존 `notes`, `worksheets`, `done`, `last`는 그대로 사용한다. 새 데이터는 선택적인 `studio` 영역에 보관한다.
- `studio`에는 공통 프로필, AI 규칙, 폴더, 저장한 프롬프트, 작성 중 구성과 카테고리별 공통 항목 선택이 포함된다.
- 기존 데이터만 있으면 JSON 백업 버전 1을 사용한다. 새 공통 정보가 있으면 버전 2로 내보내며, 현재 앱은 버전 1·2를 모두 읽는다.
- 버전 1 파일을 불러올 때 기존 공통 정보·보관함을 지우지 않는다.
- 버전 2의 공통 정보는 복원 미리보기에 독립된 항목으로 표시한다. 다른 내용이 있으면 현재 유지가 기본이고, 사용자가 선택한 경우 공통 정보·보관함 전체를 교체한다. 교체 전 보호본도 기존 방식으로 저장한다.
- 폴더를 지워도 프롬프트는 미분류로 이동한다. 저장본 삭제 시 연결된 작성 중 구성도 삭제된다는 점을 확인창에서 안내한다.
- 직접 수정한 최종본과 의도적으로 비운 최종본은 항목 변경만으로 덮어쓰지 않는다. 비어 있는 최종본은 작성 중 상태로 보관되며, 정식 저장에는 내용이 필요하다.

## 승인된 범위

AI 활용법의 학습·실습 양식은 유지하고 재사용 진입 링크만 추가했다. 새로운 이력서 카테고리와 하위 폴더는 추가하지 않았다. 추천은 카테고리와 등록된 정보에 따른 규칙 기반 표시이며, 문장 전체의 의미 충돌을 AI가 판정하는 기능은 아니다. AI API 호출·서버 저장·기기 간 동기화·배포는 수행하지 않았다.
