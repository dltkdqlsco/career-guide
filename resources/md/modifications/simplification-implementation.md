# 홈·작성·보관함 단순화

2026-10-20. `modify.md`의 세 요청을 사용자의 입력 부담과 화면 복잡도를 줄이는 변경으로 판단해 반영했습니다. 기능 삭제 대신 주 작업을 먼저 보여 주고 세부 관리는 필요할 때 열도록 정리했습니다.

## 반영 사항

- 홈의 큰 시작 영역을 **내 정보 선택하기**로 변경했습니다. 클릭하면 현재 화면에서 모달이 열리며 전공·희망 직무·관심 산업·기술 스택을 선택합니다. 모두 선택 사항이고 직접 입력과 여러 항목 선택도 지원합니다. 이전 작업은 작은 이어보기 링크로 접근합니다.
- 모달은 선택 즉시 저장하고, 닫기·완료·Escape·배경 클릭으로 닫습니다. 배경 스크롤을 잠그며 닫은 뒤 기존 스크롤과 버튼 포커스를 돌려줍니다. 내용이 길면 모달 내부만 스크롤합니다.
- 홈 사용 안내와 단계 찾기 설명은 하단 안내에 모았습니다. 상단 단계 찾기 메뉴는 계속 사용할 수 있습니다.
- 카테고리의 주 버튼을 **프롬프트 작성하기** 하나로 정리했습니다. 기존 단계별 작성 공간과 학습 흐름은 유지합니다.
- 프롬프트 편집은 모든 화면에서 **작성하기 → 결과·저장**으로 진행합니다. 기본 입력 내용은 바로 보이며, 항목 이름·종류·순서·삭제는 세부 설정에서 관리합니다. 공통 AI 설정과 저장 폴더도 필요할 때 엽니다.
- 직접 수정한 결과가 있을 때만 **선택한 항목으로 다시 만들기**를 표시합니다. 기존 저장본은 변경 저장을 주 버튼으로, 별도 복사본 저장은 추가 선택으로 제공합니다.
- **내 메모·프롬프트**는 프롬프트와 학습 메모 두 보기로 나눴습니다. 목록에는 제목·카테고리·폴더와 열기·복사만 우선 표시합니다. 이름 변경·이동·미리보기·복제·삭제는 더 보기, 폴더 관리·공통 설정·내려받기·백업은 관리 메뉴에 모았습니다.
- 새 프롬프트의 카테고리·작업 선택은 **새 프롬프트 +**를 눌렀을 때만 표시합니다.

## 저장·기존 기능

기존 단계 메모·작성값·완료 상태와 독립 저장본, 직접 편집한 결과, JSON 백업 형식을 유지했습니다. 공통 정보는 선택해서 가져오며 이미 만든 복사본을 자동 덮어쓰지 않습니다. 기존 AI 활용법의 작성 공간은 변경하지 않았습니다. 카테고리 버튼의 제목 위치 이동과 오른쪽 단계 이동 메뉴도 유지합니다.
