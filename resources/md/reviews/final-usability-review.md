# 최종 사용성 추가 검증

2026-10-17. 사용자의 다음 작업 시작 요청에 따라 실제 사용 흐름의 추가 검증을 진행했다. **현재 환경에서 가능한 Chromium 검증은 통과했지만 실제 휴대전화·Safari·운영체제 한글 입력기 검증은 완료되지 않았다.** 제품 코드에서 수정이 필요한 오류는 발견하지 못했다.

## 실행 환경

| 환경 | 설정 | 결과 |
| --- | --- | --- |
| 데스크톱 HTTP | Chromium, 1280×900 | 통과 |

| 설치된 Safari | Safari WebDriver 세션 생성 시도 | 실행 불가: 원격 자동화 비활성화 |

Safari 드라이버는 다음 응답으로 세션 생성을 거부했다: `You must enable 'Allow remote automation' in the Developer section of Safari Settings to control Safari via WebDriver.` Safari 결과를 Chromium 결과로 대체하거나 Safari 검증 완료로 표시하지 않았다. 실제 Safari 페이지 동작은 확인하지 못했다. 원격 자동화 설정을 변경하지 않았으며 검증용 드라이버는 종료했다.

## 실제로 확인한 동작

독립 브라우저 문맥과 가상 기록을 사용했다. 사용자 저장소에 접근하지 않았다.

- 실제 내부 링크 클릭과 터치 탭으로 가이드·목차·작성 탭 이동.
- 필수 입력 작성, 브라우저 키 이벤트와 Unicode 텍스트 삽입, 입력 저장과 완료 처리.
- 기존 자유 메모 수정, 새로고침 후 작성 내용·완료 상태·모드 선택 복원.
- 입력 중 화면 높이 축소 및 세로/가로 전환, 입력값 유지. 데스크톱에서는 640px 폭으로 줄여 재배치 확인.
- 키보드 좌우 화살표로 탭 전환, 작성 필드의 DOM과 값 유지.
- 화이트/다크 전환 후 입력값 보존, 가로 넘침 없음.
- 요청문 복사 버튼의 비동기 완료 안내 확인. 이 추가 검사에서는 OS 클립보드를 직접 읽어 내용까지 대조하지 않았다. 실제 클립보드 내용 대조와 선택 대체 동작은 이전 단계별·자동 회귀 검사의 범위다.
- 검색어 입력으로 결과 1개로 좁히기, Escape로 검색어를 지워 전체 45개 복구.
- 실제 JSON·Markdown 다운로드 파일을 읽어 작성한 내용과 자유 메모 포함 확인.
- 복원 미리보기의 기본 선택이 현재 기록 유지인지 확인한 뒤 한 단계를 교체. 실제 저장 결과와 직전 보호본 파일 대조.
- 잘못된 JSON 파일 선택 후 기존 기록이 그대로이고 이전 복원 실행 버튼이 남지 않는지 확인.
- 네 환경 모두 페이지 JavaScript 오류 0개. 대표 홈 화면 스크린샷 직접 확인.

제품 코드 변경이 없으므로 직전에 통과한 자동 검사 **462개·JavaScript 18개 문법 검사**를 다시 실행하지 않았다. 이번에는 위 4개 환경의 추가 상호작용 검사를 수행했다. 테스트 코드에서 기존 메모가 있을 때만 표시되는 필드와 비동기 복사 완료를 반영했고, 화면 회전 검사는 삽입 위치와 무관하게 기존 문자열이 남는지를 확인했다. 이들은 제품 오류 수정이 아니라 검사 절차 조정이다.

브라우저 스크립트와 캡처는 임시 파일이며 Git에서 제외한다. 검증용 HTTP 서버와 Safari 드라이버는 종료한다. 외부 서비스 로그인·촬영·업로드·배포·새 커밋은 수행하지 않았다.

## 아직 직접 확인해야 할 항목

다음 항목은 이번 자동화 결과로 대체할 수 없다.

- [ ] 실제 휴대전화에서 브라우저를 열고 가이드·표·모드 선택·입력을 확인한다.
- [ ] 운영체제 한글 입력기로 자모를 조합하고 중간 수정·삭제·줄바꿈·포커스 이동 후 새로고침해 비교한다.
- [ ] 실제 화면 키보드를 열고 닫거나 기기를 회전해 입력 위치와 조작 가능 여부를 확인한다.
- [ ] Safari에서 저장·복사·JSON 다운로드·복원과 file:// 직접 실행을 확인한다. 자동화하려면 Safari가 안내한 원격 자동화 설정을 사용자가 켜야 한다.
- [ ] 실제 브라우저 확대/축소와 화면 읽기 도구로 최종 확인한다.
- [ ] 사용자가 대표 목차의 문구·예시·가독성을 최종 검토한다.

터치·해상도·회전·높이 축소는 에뮬레이션이며 물리 기기·OS 화면 키보드가 아니다. Unicode 삽입과 이전의 합성 조합 이벤트는 실제 OS 한글 입력기가 아니다. 640px 재배치는 실제 브라우저 200% 확대 검사가 아니다. 로컬 서버의 `127.0.0.1` 주소는 이 컴퓨터 안에서만 열리므로 실제 휴대전화 검증에는 별도의 접근 가능한 미리보기 주소가 필요하다.
