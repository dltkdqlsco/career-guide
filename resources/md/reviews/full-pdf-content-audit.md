# 전체 PDF·학습 내용 대조 및 할루시네이션 점검

검토일: 2026-10-17. 대상: 현재 워크북 5개 가이드·45개 세부 목차의 설명, 작성 도움말, 학습용 예시, 조합 요청문, 완료·실행 상태 안내.

## 결론

45개 목차의 핵심 학습 주제와 작업 순서는 제공된 PDF에 대응한다. **PDF를 문장·예시·화면까지 그대로 복제한 구현은 아니다.** 현재 예시는 가상의 기업·경험으로 다시 작성했고, 사용자 기록 보존과 근거·미확인 구분 안내를 추가했다. 외부 도구의 실제 실행과 표절 검사 실습은 사용자가 앞서 연기한 범위다.

이번 대조에서 안내가 부족하거나 확정적으로 읽힐 수 있는 2곳을 보완했다. 점검 범위에서 실제 기업의 확인되지 않은 수치·경력을 사실로 단정하거나, 미실행 실습을 완료했다고 주장하는 추가 사례는 발견하지 못했다. 이는 모든 사실이 참이거나 향후 외부 AI 답변의 할루시네이션이 0이라는 인증은 아니다. PDF 자체의 예시에도 그대로 일반화할 수 없는 표현이 있다.

## 방법과 범위

- 중복을 제외한 PDF 5종, 128쪽을 렌더링 이미지에서 한·영 OCR로 추출했다. 페이지별 처리 성공 128/128, 빈 페이지 판정 0, 추출 문자 144,786자. OCR 오인식이 있어 숫자·표·판정이 중요한 대목은 이미지와 다시 대조했다.
- AI 활용법 전체와 기업 분석 주요 페이지를 시각 확인했고, 자기소개서·포트폴리오·면접은 전체 추출문을 대조한 뒤 쟁점 페이지를 이미지로 확인했다. **128쪽 전체를 이번에 한 장씩 모두 육안 판독했다는 뜻은 아니다.** 특히 이미지 속 작은 UI 글씨·그래프·로고를 OCR만으로 완전히 검증하지 않았다.
- `curriculum.js`의 전체 목차를 `lessons.js`, `examples.js`, `workbook.js`, 기업 분석 전용 모듈, `career-data.js`, `career-lessons.js`의 설명·예시·요청문과 비교했다. 아래 표는 핵심 요구의 대응표이며 문장별 동일성 점수는 아니다.
- 외부 서비스는 공개 공식 안내 일부만 추가 확인했다. 실제 계정 로그인, 파일 업로드, 촬영, 서비스 생성·결제·제출은 하지 않았다. 사용자가 저장한 개인 기록과 외부 AI 답변 내용은 이번 사실 검증 대상이 아니다.
- 과거 구현 보고서와 `company-research-review.html`은 이력·초기 검토안이며 현재 학습 화면과 구분한다. 이전 검사 수·보류 표현을 현재 상태로 소급하지 않는다.

## 원문과 다르게 처리한 근거

1. **실제 기업 사례와 성과:** 원문의 기업명·시스템·프로젝트 수치를 현행 사실이나 사용자 이력으로 재사용하지 않았다. 현재 학습 예시에는 가상 사례 표시가 있고 자동으로 작성칸에 넣지 않는다. 부족한 예시의 과장된 표현은 ‘피할 표현’으로 제시한다.
2. **문체와 AI 판별:** 반복 연결어·문장 길이는 편집할 단서다. 문체만으로 AI 작성 여부를 입증하거나 탐지 회피를 보장할 수 있다고 안내하지 않는다.
3. **표절/AI 검사:** 자소서 PDF 34쪽의 10%·5% 기준을 모든 기업에 통하는 제출 규칙으로 보지 않았다. 외부 실습은 보류이며 원문의 검사 권고 전체를 구현 완료했다고 주장하지 않는다. 카피킬러 공식 FAQ 페이지는 본문 추출이 되지 않아 보편적인 5% 기준의 근거를 확인하지 못했다. 실제 제출처의 규칙·인용·중복 내용을 확인해야 한다.
4. **TTL과 정합성:** 자소서 PDF 19쪽의 TTL 15분 설정만으로 정합성을 확보했다는 표현은 보장이 과하다. TTL이 끝나기 전 오래된 값을 반환할 수 있으며 갱신·무효화·경쟁 조건도 고려해야 한다. 현재 워크북은 해당 기술 예시를 복제하지 않고 실제 원인·검증 범위와 한계를 쓰도록 한다. [Redis 공식 설명](https://redis.io/blog/cache-consistency-strategies/)에서도 만료 전 오래된 데이터와 무효화 문제를 설명한다.
5. **근거 없는 수치 보강:** 자소서 PDF 31–32쪽의 첨삭은 앞 글에 없던 구체적인 전후 값·기술을 보강한다. 또한 20분→3–5분 감소율은 75–85%로, 전 구간을 80% 이상이라고 할 수 없다. 현재 첨삭 단계는 새 전후 값·기술을 기록 확인 전 채택하지 않게 안내한다.
6. **숙련도:** 포트폴리오 PDF 9–10쪽에는 서로 다른 척도와 ‘파악 불가’를 초급으로 반영한 예시가 함께 있다. 현재 구현은 한 척도를 일관되게 쓰고 근거가 없으면 미확인으로 둔다. 공인 평가나 기업 배점이 아니다.
7. **차트·변화율:** 현재 가상 데이터 10·12·11·10·12초의 평균은 11초, 6·7·6·5·6초의 평균은 6초, 시간 감소율은 약 45.5%로 계산이 맞다. 250→200ms는 20%, 20→8분은 60%다. 고정 입력 4개의 실패 2→0건은 해당 테스트 범위의 결과이며 전체 운영 품질 100%로 확장하지 않는다.
8. **영상 점수:** 면접 PDF 28쪽의 채용 가능성·성격 특성 화면은 서비스 결과 화면의 예시다. 이를 검증된 성격·감정·정직성·합격 확률로 다시 주장하지 않는다. 현재 워크북은 답변의 근거와 실제 관찰 가능한 전달 습관을 구분한다.
9. **외부 제작:** Canva·Notion 원고를 준비한 것과 실제 파일·페이지를 만든 것을 구분한다. 토글·콜아웃이 붙여넣기만으로 완성된다고 보장하지 않고 실제 편집·접근·출력본 확인을 계획하도록 한다. 10장은 원문의 구성 연습 예시이며 모든 공고의 요구가 아니다.
