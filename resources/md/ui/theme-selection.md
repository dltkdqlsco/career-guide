# 화이트·다크 모드 선택

> 이 문서는 해당 작업 시점의 기록입니다. 현재 구현 상태와 남은 작업은 [문서 목차](../README.md)를 기준으로 확인하세요.

2026-10-17 상단 헤더에 화면 모드 선택 메뉴를 추가했다. 기본은 화이트 모드이며 선택한 모드는 별도 브라우저 저장 키 `one-step-career-theme-v1`에 보관한다. 새로고침과 같은 출처의 다른 탭에서도 반영된다. 작성 기록·완료 상태·백업 양식은 변경하지 않는다. 저장 권한이 없는 환경에서도 현재 화면에서는 전환할 수 있다.

`theme.js`를 스타일 렌더링 전에 실행해 저장한 모드를 적용한다. `theme.css`에서 배경·본문·보조 설명·카드·표·폼·선택 상태·백업 화면의 색상을 지정했다. 기존 본문/보조 설명 확대와 제목·버튼·입력 글자 크기는 유지한다. 좁은 화면에서는 헤더가 줄바꿈한다.

검증: 자동 검사 455개 통과, JavaScript 18개 문법 검사 통과. 모드 기본값·저장/복원·잘못된 값·저장 실패·다른 탭 반영·작성 기록과의 분리를 확인했다. 1280/390/320px에서 두 모드로 각각 45개 목차의 3개 탭 및 공통 페이지 4개, 총 834개 페이지 상태를 검사했다. 가로 넘침·중복 ID·페이지 오류 없음. 실제 선택 후 새로고침 유지, 입력 기록 및 글자 크기 보존을 확인했다. 대표 홈·입력·예시 화면과 모드 선택 메뉴를 스크린샷으로 확인했다.

검증 파일: `.local/checks/theme-browser-check.js`, `/private/tmp/theme-tests.log`, `/private/tmp/career-theme-*.png`. 브라우저는 독립 테스트 문맥을 사용했다. 모든 색상 조합의 접근성 대비를 수치 인증한 것은 아니다. 배포·커밋은 수행하지 않았다.
